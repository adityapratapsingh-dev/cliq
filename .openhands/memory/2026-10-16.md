## Cliq app build (this repo = cliq)

Repo `/workspace/project/cliq` is a standalone **Next.js 15 App Router + TS +
Tailwind v4 + lucide-react** teen social app called **Cliq** ("Find your Cliq").
Branch `main`. Built in one session; committed as "Build Cliq...".
- `npm run build` and `npm run lint` are ZERO errors / ZERO warnings. 25.1 kB page.
- Architecture: single client app; `src/components/CliqProvider.tsx` is the whole
  state store (React context, all actions). Tabs in `src/components/tabs/*`.
  Mock data in `src/data/mockCliqData.ts`; types in `src/types/cliq.ts`.
- Accent theming: `src/lib/theme.ts` defines `ACCENTS` + `accentVars(key)` writing
  CSS vars (`--accent*`) on the app root in `CliqApp.tsx`. globals.css uses them.
- Gotcha: scaffold uses `create-next-app@15.5.4`; running it directly in a
  non-empty dir fails ("files that could conflict") — scaffold in /tmp, copy in.
- Gotcha: the classic Google sample MP4 bucket
  (`commondatastorage.googleapis.com/gtv-videos-bucket/...`) now returns **403**.
  Use `https://download.samplelib.com/mp4/sample-5s.mp4` etc., or
  `media.w3.org/2010/05/video/movie_300.mp4`, `test-videos.co.uk/...` (200/206).
- Dev server for verification: `npm run start -- -p 12000` (work host port 12000).
