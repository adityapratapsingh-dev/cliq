## 60fps mobile performance pass (PR #15, 2026-10-17)

**Measured before/after (Chromium, phone 390x844):**
- Scroll frame timing: avg 16.7ms, p95 16.8ms, 0 long frames (locked 60fps)
- `backdrop-filter` elements: 24 usages -> 0
- Inner scroll containers on a phone feed: -> 0 (document scrolls natively)
- `<img>` without loading=lazy: 23 -> 0
- Closed modals mounted: CreateModal + ProfileModal -> 0

**What actually mattered, in order of impact:**
1. `backdrop-blur-*` is the #1 scroll-jank source. A backdrop filter re-blurs
   everything behind the element EVERY visible frame. Solid #121212/#1a1a1a looks
   the same at rest and costs nothing.
2. Infinite CSS animations (mesh drift 18s, marquee, spin-disc, pulse-ring) keep
   the compositor permanently busy. Remove or make static.
3. `mix-blend-mode: overlay` (.cliq-grain) forces a compositing pass on every
   element it is applied to — it was on every media placeholder.
4. Nested scroll containers (`h-[calc(100dvh-...)] overflow-hidden`) fight native
   mobile scroll physics. On phones let the DOCUMENT scroll; only use a fixed
   inner split at `md+`.
5. Always-mounted modals bloat the feed's DOM. Mount conditionally.

**CSS/DOM gotchas:**
- `touch-action: manipulation` removes the ~300ms double-tap-zoom delay;
  `-webkit-tap-highlight-color: transparent` kills Android's blue tap flash.
  Apply to interactive elements only (not globally) so text stays selectable.
- Do NOT insert comments inside a CSS selector list (`a, /* c */ b { }`) — it can
  invalidate the whole rule. Verify with a grep of the @media block after patching.
- Dead CSS accumulates: grep each animation class for usages in src/components
  before assuming it is still needed (4 were at 0 usages).

**BIG LESSON — never regex across JSX whitespace.** A sweep script that collapsed
double spaces inside quoted strings destroyed ~9k lines by joining JSX elements
onto one line. Recovered with `git checkout -- .`. Correct approach: only rewrite
INSIDE quoted class-string literals, token by token, and never touch surrounding
markup. Also: a naive `<img ...>` regex will insert attributes inside
`onError={() => ...}` arrow bodies and corrupt them — anchor on unique className
values for multi-line tags instead.
